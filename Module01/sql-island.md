Game: https://sql-island.informatik.uni-kl.de/

Our Task Pod practised SQL Island as the introductory query exercise; Mohamed Alsayed/Hamed took the lead on Task 5.

## What we practised

- `SELECT` retrieves columns/rows from a table.
- `WHERE` filters results based on a condition.
- `LIKE` can match patterns in text.
- `COUNT` counts matching rows.
- `UPDATE` changes data (take care to restrict the target rows).
- Joins and subqueries allow questions involving multiple tables.

A **table** contains related data, a **row** is one record, a **column** is a field, and a **query** is a SQL instruction asking for data or changing it.
