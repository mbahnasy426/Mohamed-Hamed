Single-day lookup before index:

Single-day lookup after date index:
  SEARCH o USING INDEX ix_orders_ordered_on (ordered_on=?);
  SEARCH c USING INTEGER PRIMARY KEY.
Negative: date(o.ordered_on)='2026-02-14' -> SCAN o.
Positive alternative: WHERE product_id=42 ->

PASS: selective date filtering uses index; wrapped-date predicate does not.
Interpretation: the dashboard became slower after planner switched from SCAN
to repeated indexed JOIN lookups. Indexes do not automatically improve queries.
